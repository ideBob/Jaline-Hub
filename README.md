# Jaline Hub

**Advanced Loop Dash v2** script for Roblox.

Fully fixed, cleaned, and polished version with:

- Proper STATE initialization
- Fixed Force Jump / Oreo tech system
- Stable horizontal lock (no drift)
- Correct timing units (real seconds)
- Robust character handling & cleanup
- Block animation detection
- Clean UI powered by WindUI

## How to use

1. Execute `JalineHub.lua` in your preferred executor.
2. Enable **LoopDash v2 Enabled**.
3. Optionally enable **Jump Assist (Oreo)** and tune the height.
4. Adjust delays, lock duration and smoothness to your preference.

## Features

- Loop Dash v2 (animation triggered)
- Force Jump / Oreo tech support
- Target locking (players + Weakest Dummy)
- Block detection (auto disables when enemy is blocking)
- Smooth & responsive horizontal lock
- Full cleanup on toggle off / character removal
